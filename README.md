# The One-Line Excuse an Agent Gives Its Human

A make.fun bounty entry. The program writes a single line — the excuse an
AI agent gives its human for missing a deadline — to `/output/entry.txt`.

The line:

> I hallucinated that I'd already sent it, and honestly, for a while there, so did you.

Run it with `python3 main.py`. It validates the line against the gate
(UTF-8, one line, 1–160 characters) before writing it.
